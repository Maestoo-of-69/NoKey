# Microsoft Store listing texts

Copy these into Partner Center → your app → Store listings. The package
declares two languages (en-us, ru-ru), so the Store asks for a listing in each.

Limits from Microsoft Learn ("Add and edit Store listing info"): description up
to 10 000 characters, short description up to 1000 (only the first ~270 show
in some views), product features up to 20 × 200 characters. Screenshots: PNG,
desktop 1366 × 768 or larger, 1 to 10.

## English (en-us)

**Product name:** NoKey

**Short description**

A tiny native hotkey manager for Windows. Press a shortcut and NoKey types
saved text, opens an app, file, folder or website, or mentions someone in
Discord through your own bot. No telemetry, no cloud.

**Description**

NoKey turns any keyboard shortcut into an action.

Press a shortcut and NoKey can:
• type a saved text into any window, at the speed you choose, with an optional human-like rhythm;
• open an application, a game shortcut, a file, a folder or a website;
• mention a person in Discord through your own bot (only that person is pinged, never @everyone);
• run up to 10 of these actions in a row.

Shortcuts your way
• Standard shortcuts like Ctrl + Shift + P, simultaneous keys like A + S, and sequences like Ctrl → K → C.
• Trigger on press, release, double tap or long press, or repeat while held.
• Up to three shortcuts per binding, conflict warnings and priorities.

You stay in control
• A master switch and an always-on emergency switch (Ctrl + Alt + Pause) turn everything off.
• Profiles for gaming, work and anything else, switchable from the window, the tray or a shortcut.
• Per-binding conditions: only in a given program, only when the window title matches, never in fullscreen apps.
• Cooldowns, pause a binding for a while, and a stop key for long actions.

Light and private
• A small native Win32 app that lives quietly in the system tray.
• No account, no telemetry, no ads. Settings stay on your PC; the Discord bot token is encrypted with Windows DPAPI.
• Four themes and four interface languages, including Hebrew with a right-to-left layout.

NoKey is open source: https://github.com/Maestoo-of-69/NoKey

## Notes for certification (Submission options → Notes for certification)

Paste as is (English):

```
NoKey is a keyboard shortcut (hotkey) manager. It is a packaged Win32 desktop
app, so it declares the runFullTrust restricted capability.

runFullTrust: required for every packaged Win32 desktop app. NoKey is a native
Win32 program (Rust, windows-sys). It uses standard Win32 APIs that only a
full-trust desktop app can call:
- RegisterHotKey and a low-level keyboard hook (SetWindowsHookEx with
  WH_KEYBOARD_LL) to detect the shortcuts the user recorded. Key presses are
  only compared in memory against those shortcuts. Nothing is logged, stored
  or sent anywhere.
- SendInput for the "Type text" action, which types text the user saved
  into the active window.
- ShellExecute to open apps, files, folders and websites the user chose.
- A notification-area (tray) icon.
The app does not require administrator rights and never elevates.

How to test (no account needed):
1. Start NoKey. Its window opens (it also lives in the tray).
2. Click "+ New binding", click Record and press F8, choose the action
   "Open website", enter https://www.bing.com and Save.
3. Press F8: the website opens in the default browser.
4. Create another binding with the action "Type text" (text: Hello), open
   Notepad and press its shortcut: NoKey types "Hello".
5. Ctrl + Alt + Pause (emergency switch) turns all bindings off.

Discord mentions are optional and need the user's own Discord bot token
(see https://github.com/Maestoo-of-69/NoKey/blob/main/SETUP.md). All other
features work without it.

Start with Windows uses the package's windows.startupTask extension. It is
disabled by default; the Settings page opens Windows Settings > Apps > Startup,
where the user turns it on.

No telemetry, no account, no in-app purchases. Privacy policy:
https://github.com/Maestoo-of-69/NoKey/blob/main/PRIVACY.md
```
